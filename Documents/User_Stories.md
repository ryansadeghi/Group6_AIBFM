# User Stories
| US ID | User Story | Stakeholders | Acceptance Criteria | Parent Use Case | State | Test Case |
|------|-----------|-------------|-------------------|----------------|------|----------|
| US-01 | As a user, I want to see match predictions so that I know possible outcomes | User | Given a selected match, when prediction is generated, then results are shown | UC-01 | Queued | TC-01 |
| US-02 | As a user, I want to see win/draw/loss probabilities so that I can understand chances | User | Given a prediction, when displayed, then probabilities are visible | UC-01 | Queued | TC-02 |
| US-03 | As a user, I want team statistics included so that predictions are more informative | User | Given a match, when stats loaded, then team stats are shown | UC-02 | Queued | TC-03 |
| US-04 | As a user, I want recent team form so that I can judge performance trends | User | Given recent matches, when analyzed, then form is calculated | UC-03 | Queued | TC-04 |
| US-05 | As a user, I want a simple interface so that I can use the system easily | User | Given no training, when using the app, then UI is understandable | UC-04 | Queued | TC-05 |
| US-06 | As an analyst, I want data sources shown so that predictions are transparent | Analyst | Given a prediction, when viewed, then sources are listed | UC-05 | Queued | TC-06 |
| US-07 | As a user, I want updated predictions so that results stay accurate | User | Given new data, when model runs, then predictions update | UC-06 | Queued | TC-07 |
| US-08 | As an admin, I want to manage datasets so that data stays accurate | Admin | Given admin access, when editing data, then changes are saved | UC-07 | Queued | TC-08 |
| US-09 | As a user, I want to see prediction history so that I can review past matches | User | Given past matches, when requested, then history is shown | UC-08 | Queued | TC-09 |
| US-10 | As an admin, I want to monitor system status so that issues are detected | Admin | Given dashboard access, when viewed, then system status is visible | UC-09 | Queued | TC-10 |
